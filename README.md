# dissertation-replication-package-

This replication package contains the Stata code required to reproduce all tables, figures and results for my doctoral thesis titled “The Effect of Education on Mobility, Labour Market Integration and
Voting Behaviour”, and is designed to be permanently accessible. Please refer to the respective ‘Read Me’ files within the subfolders, which explain the exact replication process. Sensitive data is required for the respective papers, which must be requested directly from the original sources.
